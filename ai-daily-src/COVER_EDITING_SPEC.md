# AI 日报封面与剪辑规范 · V1

## 风格来源和目标

参考用户提供的 5 分 16 秒科技解说短视频及账号封面截图（只借鉴普遍的新闻解说节奏与信息组织方式，不复制其画面、音乐、配音或独特版式）。

- 画幅：竖屏 1080×1920，30 FPS
- 配色：深蓝/黑蓝科技网格；白色主标题、青色栏目标签、绿色第二行价值点
- 画面：真实资讯截图优先、截图缓慢推近、原创网页式信息卡、清晰可读大字幕
- 真实性：封面图、新闻截图、口播结论和日期都必须指向同一期 HEX2077 日报，不得张冠李戴
- 授权：从源站找到素材并不能自动获得转载授权。公开发布前需审核或取得适当授权；若不符合要求，回退为原创信息卡

## 封面选择

1. 优先选中当天日报被摘要采用的新闻条目的实际图片，不是随意检索的图库图片
2. 画质至少 280×220，且像素面积大于 115000；不使用二维码、低质量图标或无关头像做主视觉
3. 优先产品界面、设备实拍、演示截图、科研图表；候选按栏目权重、alt 描述、清晰度和正文关联性排序
4. 选取 1 张主图 + 最多 2 张辅助图，图片不足时自动缩减数量；无图时显式采用原创信息卡，不生成假人物、假产品界面
5. 顶部：固定『AI日报』巨型标题 + 真实期号日期
6. 中下部：来自该栏目摘要的事实性钩子 + 来自另一栏目摘要的第二行亮点，避免未经证实的惊叹语、对立叙述、销量与结论
7. 底部保留“何夕2077 · 摘要整理”和资料来源提示；PNG 单独导出

## 正文剪辑

- 先用引子突出本期重点（不超过首段口播总时长）
- 按当期日报实际栏目划分章节；每章包含标题、1–2 个资讯点、简短解读
- 每章优先剪入对应案例截图，分段淡入并以缓慢推近展示，不强行使用无关素材
- 段落配图缺失时，显示原创新闻证据卡，包括栏目名、摘要、案例短摘
- 中文口播使用 Kokoro。动态字幕按分句与场景时长近似分配，非逐字强制对齐
- 结尾提醒“完整来源与图片出处见 sources.json”，所有日期均为日报原始发布日期

## 发布文件

- `ai-daily/latest.mp4`：成片
- `ai-daily/latest-cover.png`：抖音、小红书封面，1080×1920
- `ai-daily/latest.sources.json`：日报发布日期、条目原文链接、选中图源、画面摘要和封面数据
- GitHub Pages：`https://cativen.github.io/ai-daily/`

## 故障降级

- 日报当期不足或无法正常解析：日志报错，不编造当天新闻
- 小模型无法可靠生成口播：停止该期任务，不发布虚构内容
- 真实图片不可下载/不合规/低清：回退为原创信息卡；`coverFallback=true` 标记
- Remotion 或 FFmpeg 生成失败：不发布空封面、空视频
- 免费 GitHub Runner 的时长、内存与资源不保证持续稳定。需每次检查 Actions 日志

## 当前测试限制

改动已提交 GitHub；Remotion 视频与封面导出的端到端运行状态需要以 GitHub Actions 最新一次结果为准，不能仅凭代码提交视为渲染成功。
