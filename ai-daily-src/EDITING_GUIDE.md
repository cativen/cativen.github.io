# AI 日报竖屏视频：剪辑风格 V2

## 参考方向
用户提供的抖音作品短链仅作为“快节奏科技资讯解说”的节奏参考，当前执行环境无法逐帧播放，**不是原视频复刻**。不要复用原视频的配音、音乐、镜头或画面。

## 分镜规则
1. 开头 3~8 秒：问题式标题，日报的实际发布日期，醒目的 AI DAILY 品牌视觉
2. 每个栏目：一个大标题 + 1~2 个资讯点（由 Qwen 依据日报文字原创提炼）
3. 有相关截图：在同一栏目内使用最多两张、由 HEX2077 正文直接提供的图片。做缓慢推近、淡入、信息条叠加和截图片段之间的切换
4. 无相关截图：显示“原创信息卡 / 案例摘要”，不要塞无关模型图片，更不能生成虚假产品 UI 冒充截图
5. 语音：Kokoro 本地中文配音；字幕按照分句文字长度近似分配时长，不声称逐字精确对齐
6. 结束：标注「摘要来源：何夕2077」，具体出处保存在 latest.sources.json

## 素材与权限
- 自动拉取的图片仅限 hex2077.dev 和 source.hex2077.dev 主站分发的 PNG/JPEG/WEBP/AVIF/GIF，拒绝重定向到第三方下载主机
- 图片每张限制 9MB，FFmpeg 转为最长边不超过目标展示尺寸的 JPEG
- 选中案例和图片要属于同一个日报条目；不要错配新闻
- 记录图源 URL 和图片说明到 latest.sources.json；出现版权声明或禁止转载时，应删除该素材
- 视频音轨**不**抓取抖音原视频、第三方视频或背景音乐。公开发布前请确认图片等素材的授权范围；**注明来源不等于取得许可**

## 运行
- `free`: HEX2077 最新可得日报 → Qwen2.5:1.5b → Kokoro → Remotion → FFmpeg → Pages
- `demo`: 使用离线虚构文案生成静音 MP4，只验证视频模板
- GitHub Actions: https://github.com/cativen/cativen.github.io/actions/workflows/ai-daily.yml
- 预览: https://cativen.github.io/ai-daily/

## 已知风险
- 目前无法在对话环境直接播放用户提供的抖音短视频并逐帧分析
- 自动化流水线自修改后**仍需 GitHub Actions 成功运行进行完整验证**
- 小模型可能没有严格按 JSON 要求输出；类别摘要会在不满足安全验证时失败，而不是编造
- GitHub Actions 标准 Runner 资源受限；全流程视频渲染的稳定性仍需监测
- HTML 结构、媒体格式与站点访问权限变动会影响采集
